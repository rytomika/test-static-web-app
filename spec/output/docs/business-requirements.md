## 2. 概要

- **対象業務 / 目的**: トヨタマップマスター（TMI）調達室における CP（Competitive Procurement）対応業務。ベテラン依存・情報分散・継承困難な調達ノウハウを組織のナレッジ資産として蓄積し、Azure AI（Azure AI Search・Azure OpenAI・Microsoft Foundry）による検索・判断支援、将来的な調達 AI エージェント化につなげる。
- **プロジェクト背景**: 少人数の調達室で多様な案件に対応しており、判断が属人化し、過去案件・契約書・見積書などの情報が SharePoint / ローカル / メールに分散している。業務継承・人材育成が難しく、担当者により判断品質にばらつきが生じている。
- **スコープ**: 短期（M365 Copilot による省力化）→ 中期（SharePoint / Graph / Fabric によるナレッジ基盤化）→ 長期（Azure AI Foundry による検索・判断支援・自律エージェント化）の3段階構想のうち、初期 PoC として「過去案件検索」「調達FAQ・ナレッジ検索」「契約レビュー支援」の3テーマに着手する。本アプリ開発では、これらのうち Azure App Service にデプロイする Web アプリケーションとして実現する範囲を対象とする（対象テーマの確定は本ドキュメント合意後に行う → 未確定事項 #1）。

## 4. ユーザーストーリー

- As a 調達室担当者, I want 過去の類似案件を自然言語で検索したい, so that ベンダー選定や見積評価の判断を過去実績に基づいて効率的に行える.
- As a 調達室担当者, I want 調達規程・過去のFAQをチャットで問い合わせたい, so that ベテランに聞かずに自分で確認・自己解決できる.
- As a 調達室担当者, I want 契約書のレビュー支援を受けたい, so that 契約審査の判断品質のばらつきを減らせる.
- As a 調達室 室長, I want 誰にどのくらい業務が偏っているか（属人化ポイント）を可視化したい, so that ナレッジ化すべき対象を優先順位付けできる.

## 5. 業務フロー

CP対応業務フロー（約10ステップ）: 01 要件受領 → 02 市場調査 → 03 ベンダー選定 → 04 RFP作成 → 05 見積取得 → 06 見積評価・比較 → 07 稟議作成 → 08 契約審査 → 09 契約締結 → 10 事後管理。

各ステップの判断・成果物（契約書・見積書・稟議書・メール・Teams）が分散し、属人化・再利用困難・継承困難・品質ばらつきという課題がある（詳細: [staging](../staging/20260714_%20TMI_調達ナレッジ資産化.pdf.MD)）。
